## Контракт фронт ↔ бэк (B выкладывает к 19:00, дальше меняем только вдвоём)
Фронт не считает деньги сам и не ходит в AI напрямую. Он только вызывает это:
- `lib/types.ts` — `Plan`, `Money` (баланс, зарплата, частота, дата следующей, аренда и её день), `AppState`, `TimelineDay`, `Timeline`, `Purchase`, `Verdict`.
- `lib/plan.ts` — `buildTimeline(state, today): Timeline` (6 недель, статус `ok | tight | short`, нижняя точка), `checkPurchase(state, purchase, today): Verdict` (`fits | not_now`, на сколько не хватает и когда, лучший день).
- `lib/sample.ts` — `getSampleState(today): AppState` (образец данных от сегодняшней даты).
- `lib/storage.ts` — `loadState(): AppState | null`, `saveState(state)`, `clearState()` (localStorage, схема zod, версия).
- `POST /api/read-plan` — вход `{ text?: string, imageBase64?: string }` → `{ plan: Plan }` или `{ error: string, code: "no_keys" | "unreadable" | "timeout" | "too_large" }`.
- `lib/ics.ts` — `buildIcs(state, today, baseUrl): string` (даты списаний, напоминание накануне, в каждом событии ссылка `${baseUrl}/?due=YYYY-MM-DD` на check-in).

**Уже в `main` (коммит 34d5bb0, 19:10):** всё ниже работает по-настоящему, не заглушки. `Money` получил поле `weeklySpend` (траты в неделю: без него лента нереалистично растёт); `/api/read-plan` принимает ещё `today`. Для фронта готовы хуки `useAppState()` и `useToday()` (`hooks/`) и форматтеры `formatUSD`, `formatShort` (`lib/dates.ts`). Ожидаемые числа демо — `demo_inputs.md`.

**Добавлено после ревью идеи (14.11, `docs/idea-review.md`):**
- `Verdict.fitsByDay: { date: string; fits: boolean; lowest: number }[]` — 42 дня, для полоски «в какие дни покупка влезает».
- `Verdict.paydaySync: { buyOn: string; debits: string[] } | null` — день покупки, при котором все списания падают на зарплаты. `null`, если зарплата не раз в неделю и не раз в две недели или такого дня нет в 42 днях.
- `paydaySync(state, plan, today): { onPayday: number; total: number }` (`lib/plan.ts`) — для значка на карточке плана («On payday», «2 of 3 before payday»).
- `Timeline.paydays: string[]` — зарплаты в окне. Фронт берёт вторую как конец бесплатного периода Plus.
- `lib/image.ts` — `shrinkImage(file: File): Promise<string>`: ужимает скриншот до 1280 px JPEG и отдаёт base64 для `/api/read-plan`.
- `GET /api/health` → `{ ok: true, providers: { llm1: boolean, llm2: boolean, llm3: boolean } }` — только `true/false`, никогда не ключи.
- `AppState.plus: { since: string; trialEnds: string; via: "stripe_test" | "demo" } | null` — открыт ли Plus. Пока `null`, лучший день, полоска, Payday Sync и точная нехватка закрыты пейволом (FAQ Q37: пейвол — минимум).
- *Should:* `POST /api/checkout` → `{ url }` — Stripe Checkout в тестовом режиме (подписка $29.99/год, пробный период до второй зарплаты); `GET /api/checkout/confirm?session_id=…` → `{ ok: boolean }`. Ключ `STRIPE_SECRET_KEY` (`sk_test_…`) только в `.env` на сервере. Без ключа фронт показывает демо-checkout.
- *Could:* `Timeline.lowest.topPlanId` — какой план сильнее всего тянет нижнюю точку вниз (объяснение по тапу).

**Правила кода (B следит, A не нарушает):** даты — строки `YYYY-MM-DD`; суммы — целые центы, форматирует только фронт; `today` берётся только в браузере и передаётся в функции; в один день зарплата считается раньше списаний; localStorage читаем после монтирования, битые данные сбрасываем; нерабочие кнопки прячем, а не оставляем (FAQ Q85).
